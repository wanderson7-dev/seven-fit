# Seven Fit — CuttingOS

App de acompanhamento de cutting personalizado.

## Funcionalidades
- Dashboard com macros do dia
- Registro de dieta com scanner de código de barras
- Leitura de tabela nutricional via IA (Claude Vision)
- Registro de treino com séries aquecimento/válida e histórico
- Acompanhamento de peso e % BF
- Fotos de progresso semanais
- Histórico filtrável de dieta e treino

## Deploy
Hospedado na Vercel como site estático.
